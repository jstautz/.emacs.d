This is my Emacs config. There are many configs like it, but this one is mine.

Rebuilt from scratch for Emacs 31 in late 2026. Previously I'd been using org-babel to organize my config in a [[http://en.wikipedia.org/wiki/Literate_programming][literate programming]] way, but for the sake of simplicity I've gone back to plain ol' elisp.

** What's in here

- =early-init.el= --- Fix native compilation on macOS 27+, hide toolbars before anything renders.
- =init.el= --- Everything except org-mode.
- =org-mode-init.el= --- My org-mode setup. It's gnarly but works for me.
- =custom.el= --- Scratch space for =M-x customize=. Changes I like will eventually graduate to =init.el=.
- =lisp/= --- Single-file libraries that aren't packages (e.g. =org-depend.el=, from org-contrib).
- =elpa/= --- Third-party packages vendored in. 
- =resources/= --- Sounds for org-pomodoro.

** Handling packages

- *Built-in options prioritized.* Emacs 31 ships with a lot of what I used to install: =use-package=, fido, latest org-mode, etc.
- *Packages are checked in.* I wanted to make sure fresh checkouts work out of the box and packages are pinned. Any package upgrades are intentional via =M-x package-upgrade= + a commit.
- *Compiled files aren't checked in.* On a fresh clone, the first launch byte-compiles everything in =elpa/=. Takes a few seconds.

** Dependencies

- Emacs 31+ on macOS
- =brew install aspell terminal-notifier= (spell-checking + notifications)
